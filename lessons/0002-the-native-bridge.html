Lesson 2: The Native Bridge

Connecting the Virtual Machine to the Physical World.

A JVM is a "sandbox." By design, Java code cannot touch hardware directly. It can't flip a GPIO pin, write to a UART register, or allocate raw physical memory. To do these things, the JVM uses Native Methods.

The "Native" Concept

In Java, a method marked with the native keyword has no Java body. Instead, it's a signal to the JVM: "Look up the implementation of this function in the host language (C++ in our case) and execute it."

The Bridge: The Native Bridge is the layer of C++ code that implements these functions. If the JVM wants to print a character to the screen, it calls a native method, which in turn calls the actual hardware driver (e.g., Circle's UART driver).

FlintJVM's Native Architecture

FlintJVM doesn't force you to implement every single Java API. Instead, it provides a set of Native Interfaces. If you implement the functions defined in these headers, the JVM gains those capabilities.

Take a look at the structure in addon/FlintJVM/Native/Inc/:

HeaderResponsibilityExample Native Function
flint_native_system.hCore OS tasks (Time, Threads, Exit)native_system_get_time()
flint_native_uart.hSerial communicationnative_uart_putc()
flint_native_pin.hGPIO controlnative_pin_set()
flint_native_math.hOptimized math operationsnative_math_sin()

How the Linkage Works

The process follows this chain:

  1. Java Code: Calls System.out.println("Hi").
  2. JVM Execution Engine: Recognizes the call is to a native method.
  3. Native Bridge: The JVM looks up the function pointer for the native implementation.
  4. C++ Driver: Your implementation of native_uart_putc writes a byte to the RPi UART register.

Your Turn: Audit the Interface

To port FlintJVM to the Raspberry Pi, your first task is to identify the "Minimum Viable Interface." You don't need to implement everything at once. To get a "Hello World" working, you only need:

  1. System Basics: A way to get the current time or handle the JVM's startup.
  2. UART Output: A way to send characters to the serial console.
Challenge: Explore the addon/FlintJVM/Native/Inc/ directory. Find flint_native_uart.h and flint_native_system.h. See if you can identify the exact C++ function signatures you will need to implement.
