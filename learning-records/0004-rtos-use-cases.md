# RTOS use cases surveyed

The user asked about RTOS use cases. Covered four categories (embedded control, data acquisition, industrial automation, safety-critical) and the grey zone where the BBAI project lives — no hard deadlines, but RTOS chosen for simplicity and transparency. Established the screening question: "does a late answer cause damage?" as the litmus test for RTOS necessity.

**Implication:** The user's RTOS is a pedagogical project, not a deadline-driven one. This means we can make different tradeoffs (e.g., run-to-completion for some operations, relaxed timing in early versions) without real-world consequences. Future sessions can introduce hard deadlines as stretch goals.
