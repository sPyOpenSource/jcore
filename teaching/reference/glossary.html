RPi Boot Chain — Glossary

Canonical terms for this workspace. Every lesson, reference, and record should adhere to these definitions.

VideoCore (VC)
Broadcom's GPU/DSP coprocessor that boots first on all Raspberry Pi SoCs. It owns the boot chain up to the point where it releases the ARM CPU from reset. RPi 1-3 use VideoCore IV; RPi 4 uses VideoCore VI.
Avoid: "GPU" alone (ambiguous with graphics)
ROM bootloader (Stage 1)
Mask-programmed boot code in the SoC ROM. Runs on the VideoCore immediately after power-on. Initialises clocks, reads OTP to determine boot mode order, then loads Stage 2.
bootcode.bin (Stage 2, legacy)
Second-stage bootloader loaded from SD card (or USB) into the VideoCore's L2 cache. Enables SDRAM, then loads start.elf. Used on RPi 1-3 and early RPi 3B+. Superseded by SPI EEPROM bootloader on RPi 4+.
SPI EEPROM bootloader (Stage 2, RPi 4+)
Replaces bootcode.bin on RPi 4/5. Stored in SPI-attached EEPROM. Configurable via BOOT_ORDER to try SD, USB, network, NVMe. Executed by the VideoCore ROM.
start.elf (Stage 3 / GPU firmware)
Proprietary VideoCore firmware blob loaded from the SD card boot partition. Parses config.txt, applies device tree overlays, sets up memory split, and loads the ARM kernel image. RPi 4 uses start4.elf.
config.txt
Configuration file on the boot partition, parsed by start.elf. Controls kernel image name, ARM mode (64-bit vs 32-bit), memory split, device tree selection, UART, GPIO, and hundreds of other hardware parameters.
armstub (armstub8.bin)
Optional AArch64 secondary program loaded by start.elf before the kernel. Used to set up exception levels (drop from EL3 to EL2/EL1), configure the GIC, and wake secondary cores. RPi 3+ with AArch64.
DTB / Device Tree Blob
Binary description of hardware, compiled from .dts source. start.elf selects the correct .dtb based on board revision, applies overlays, and passes it to the kernel in register x0. Located on the boot partition.
kernel8.img
Default filename for a 64-bit (AArch64) kernel image on RPi 3+ and RPi 4. Loaded by start.elf at 0x80000. Must be a raw binary (not ELF).
Avoid: kernel.img (implies 32-bit), kernel7.img (32-bit RPi 2/3)
kernel load address
Physical address where start.elf places the kernel image before releasing ARM. 0x80000 for AArch64 (kernel8.img), 0x8000 for AArch32 (kernel.img). Can be overridden with kernel_address in config.txt.
BOOT_ORDER
EEPROM bootloader config (RPi 4+) that specifies the order of boot media to try. Hex value: 0xf41 means SD → USB → network → STOP (default). Each digit maps to a boot mode.
GPU memory split
How much of the 1GB+ RAM is reserved for the VideoCore GPU vs. given to the ARM CPU. Configured via gpu_mem= in config.txt. The kernel only sees the ARM portion.
Mailbox interface
IPC mechanism between the ARM CPU and the VideoCore GPU. Used by the kernel to query clock rates, get MAC address, set resolution — after the GPU firmware has already booted.
