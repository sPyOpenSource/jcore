x86-64 Register Reference

This table summarizes the mapping between legacy 32-bit registers and their 64-bit counterparts.

64-bit Name 32-bit Name 16-bit Name 8-bit Name (Low) 8-bit Name (High) Common Use
RAX EAX AX AL AH Accumulator / Return Value
RBX EBX BX BL BH Base Register
RCX ECX CX CL CH Counter / Loop
RDX EDX DX DL DH Data / I/O
RSI ESI SI SIL - Source Index
RDI EDI DI DIL - Destination Index
RBP EBP BP BPL - Base Pointer (Stack Frame)
RSP ESP SP SPL - Stack Pointer
R8-R15 R8D-R15D R8W-R15W R8B-R15B - General Purpose
Note: Accessing the 32-bit part of a 64-bit register (e.g., EAX) will zero-extend the result into the upper 32 bits of the 64-bit register (RAX).
